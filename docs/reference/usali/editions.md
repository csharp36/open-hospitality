# USALI Editions

- **11th Revised Edition** — published 2014, effective Jan 2015. Still in active use.
- **12th Revised Edition** — unveiled July 2024 (HFTP / AHLA / Global Finance Committee),
  **mandatory adoption date January 1, 2026.** Forward-looking default for the engine.
- Copyright owned by **HFTP**; revisions overseen by AHLA's Financial Management Committee.

## Design implication

Support both editions. Make `usali_edition` (11 / 12) a first-class dimension of the
mapping dictionary — the same PMS code can map to a different schedule between editions
(see `schedules.md` for the 12th-edition deltas).
