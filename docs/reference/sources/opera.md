Generated by Oracle Reports 12.2.1.3.0. This is the **config/catalog export** (the code
dictionary), not a daily financial file.

## Structure (per `<G_TRX_CODE>`)
- `TRX_CODE` — numeric code, e.g. `1000` *Accommodation, `1010` No Show, `7100` TOT 10%, `9000` Cash.
- `TC_TRANSACTION_TYPE` — `C` charge, `FC` payment/settlement, `PK` package.
- `TC_GROUP` / `TC_SUBGROUP` — hierarchy that maps almost 1:1 to USALI schedules.
- `D3` — description.
- `ADJ_TRX_CODE` — linked adjustment/reversal code.

## Assessment
Rich and clean — real numeric codes + hierarchy. High-confidence mapping source.
The MISC group (132 codes) is the main manual-review effort.

## Daily deliverables (see `ingestion-contract.md`)
The real daily feed arrives as **PDF** (emailed to Inn-flow). Three Opera reports:
- **Trial Balance** (`trial_balance`) — the financial feed: real trx codes + Today amounts,
  grouped Revenue / Non-Revenue / Payment. Codes match this catalog (`1000`, `7100`, …).
  → primary source for `pms_daily_financial_stage`.
- **Manager Flash** (`manager_report`) — statistics/KPIs (occupancy, ADR, RevPAR, room counts).
- **Market Code Statistics** (`stat_dmy_seg`) — room revenue by market segment (Transient/Group/Contract split).

**Role of this catalog:** seed the *full* 478-code mapping dictionary; the Trial Balance
exercises the subset of codes with daily activity.
